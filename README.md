# Brench Interview Preparing

用于整理大模型算法岗、工程实践与面试准备材料的个人学习仓库。

## 内容概览

- `basic_knowledge/`：算法、PyTorch 与大模型基础知识，以及手撕代码练习。
- `brench_resume/`：中英文简历源文件、参考材料与构建脚本。
- `project_review/`：项目复盘与实践，包括 Agent、GRPO、检索规划和数据分析等主题。
- `GIT_SUBMODULE_SYNC.md`：子仓库初始化、更新及提交指针的操作说明。

部分独立项目以 Git Submodule 形式维护。首次克隆后可执行以下命令初始化：

```bash
git submodule update --init --recursive
```

如需同步子仓库或在子仓库内开发，请参阅 [GIT_SUBMODULE_SYNC.md](GIT_SUBMODULE_SYNC.md)。
