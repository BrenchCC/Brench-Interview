# 49. 字母异位词分组

## 题目描述

给定一个字符串数组 `strs`，请将其中的字母异位词组合在一起，并按任意顺序返回分组结果。

字母异位词由重新排列源单词中的所有字母得到，组成两个单词的字母及其出现次数均相同。

### 示例 1

```text
输入：strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出：[["bat"], ["nat", "tan"], ["ate", "eat", "tea"]]
解释："nat" 和 "tan" 是一组字母异位词，"ate"、"eat" 和 "tea" 是一组字母异位词，"bat" 单独成组。
```

### 示例 2

```text
输入：strs = [""]
输出：[[""]]
```

### 示例 3

```text
输入：strs = ["a"]
输出：[["a"]]
```

### 约束条件

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写英文字母

## 题解

### 核心思路：排序结果作为哈希键

字母异位词包含完全相同的字母，并且每个字母的出现次数也相同，因此将一组字母异位词分别排序后，会得到相同的字符串。例如，`"eat"`、`"tea"` 和 `"ate"` 排序后都得到 `"aet"`。

使用哈希表保存分组结果：将排序后的字符元组作为键，将具有该特征的原字符串追加到对应列表中。`sorted(item)` 返回的列表不能作为字典键，因此代码用 `tuple(sorted(item))` 得到可哈希的元组。遍历结束后，返回哈希表中的所有列表。

### 算法步骤

1. 创建一个值类型为列表的哈希表 `ans`。
2. 遍历 `strs`，对当前字符串的字符进行排序，并将结果转换为元组 `key`。
3. 将当前字符串追加到 `ans[key]` 对应的列表中。
4. 返回哈希表中的全部分组。

### 示例解析

对于 `strs = ["eat", "tea", "tan", "ate", "nat", "bat"]`，各字符串对应的键如下：

| 排序键 | 原字符串 |
| --- | --- |
| `('a', 'e', 't')` | `"eat"`、`"tea"`、`"ate"` |
| `('a', 'n', 't')` | `"tan"`、`"nat"` |
| `('a', 'b', 't')` | `"bat"` |

具有相同排序键的字符串被追加到同一个列表中，由此得到所需的分组结果。

### 正确性说明

对于任意两个字符串：

- 如果它们是字母异位词，那么它们包含的字符及各字符出现次数相同，排序结果必然相同，因此会被分到同一组。
- 如果它们的排序结果相同，那么它们包含的字符及各字符出现次数必然相同，因此它们是字母异位词。

所以，以排序结果作为哈希键，能够将且仅将字母异位词分到同一组，算法正确。

### 复杂度分析

设字符串数量为 `n`，单个字符串的最大长度为 `k`。

- 时间复杂度：`O(n × k log k)`，每个字符串都需要进行排序。
- 空间复杂度：`O(n × k)`，哈希表需要保存排序键和分组结果。
